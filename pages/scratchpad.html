Development separation

Execution repo stays separate from research repo

The first phase is still Raspberry Pi plus IB Gateway connectivity. Strategy work should be pulled across only after order visibility and reconciliation exist.

1

IBKR foundation

Keep the IBKR repo focused on guarded manual orders, paper-first operation, kill switch behavior, and live-trading gates.

2

Add positions, executions, account summary, and reconciliation before allowing automated strategy execution.

qqq_test research lab

Use qqq_test for features, labels, backtests, PostgreSQL data, and signal persistence. Do not copy dashboard or cron code into IBKR.

Let qqq_test produce a dated signal artifact or DB row. IBKR should first read it and print a dry-run order intent.

Momentum switch rule

Enter on an n-bar streak, switch on an x-bar opposite streak

The second idea moved from fixed timing to price action. The tested rule used 1-minute close-to-close moves, allowed at most one switch, and exited by 11:00 ET.

Observe openStart at 09:30 ET with 1-minute QQQ closes.
Detect streakIf price rises for n bars, go long. If price falls for n bars, go short.
Track opposite moveAfter entry, watch for x consecutive bars against the position.
Switch onceReverse the position when the opposite streak appears.
Exit latestClose by the last bar before 11:00 ET.
